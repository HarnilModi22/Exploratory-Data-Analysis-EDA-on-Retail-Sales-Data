# Exploratory-Data-Analysis-EDA-on-Retail-Sales-Data
Project Title

EDA on Retail Sales Data

Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on retail sales data to identify trends, patterns, and insights for better business understanding and decision-making.

Steps Performed
Loaded and cleaned the dataset
Checked missing values and duplicates
Calculated descriptive statistics:
Mean
Median
Mode
Standard Deviation
Performed product analysis
Created visualizations:
Heatmaps
Bar charts
Line plots
Analyzed trends and relationships in the dataset
Generated recommendations based on insights

Tools & Technologies Used
Python
Google Colab
Pandas
NumPy
Matplotlib
Seaborn

Outcome

The dataset was successfully analyzed using EDA techniques. Visualizations and statistical analysis helped identify important trends and patterns in the retail sales dataset.
